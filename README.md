# ECE 228 - Beijing PM2.5 forecasting

Team 17 - Ting-Yu Yu, Yun-Chen Tsai

Short-term PM2.5 prediction on the
[Beijing Multi-Site Air Quality dataset (UCI)](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data).
Twelve monitoring stations, hourly readings, 2013-03-01 through 2017-02-28.

## What we compare

- **Persistence baseline** - just predict `y_{t+h} = y_t`.
- **Ridge regression**, **random forest**, **gradient boosting** -
  flatten the 24-hour window and one-hot the station id.
- **LSTM**, **GRU**, **Transformer encoder** - run the 24-hour window
  through a sequence model with a station embedding.

We run all of these in two input settings:

- **global**: one model across all 12 stations, station id as a feature
  / embedding. Each example only sees that station's own history.
- **multi**: same as global but each timestep also gets the channel-wise
  mean of the *other* 11 stations as context (target station is masked
  out so we don't leak the label).

...at two forecast horizons (1 hour and 6 hours ahead).

## How to reproduce

```bash
# 1. download the dataset (skip if you already have data/raw/PRSA_*)
mkdir -p data/raw && cd data/raw
curl -sSL -o aq.zip \
  https://archive.ics.uci.edu/static/public/501/beijing+multi+site+air+quality+data.zip
unzip -q aq.zip && unzip -q PRSA2017_Data_20130301-20170228.zip
cd ../..

# 2. run the full sweep (about 1-2 hours on Apple Silicon)
python -m src.run_experiments

# 3. (optional) re-train sequence models at h=6 with tuned hyperparameters
python -m src.rerun_h6

# 4. generate per-station table
python -m src.analyze_predictions

# 5. generate the markdown + latex report inputs
python -m src.make_report
python -m src.make_latex_tables

# 6. compile the latex report
cd report && pdflatex report.tex && pdflatex report.tex
```

Useful flags for `run_experiments`:

```
--settings        global multi          # which input settings to run
--horizons        1 6                   # which forecast horizons
--baselines       linear rf gbm         # subset of baselines
--sequence        gru lstm transformer  # subset of sequence models
--skip-baselines / --skip-sequence
--epochs          15
--max-rf-n / --max-gbm-n                # cap tree-model training rows
```

## A few things to know

- The split is **time-based**: train is 2013-2015, val is the first half
  of 2016, test is the second half of 2016 plus Jan-Feb 2017. We never
  train on a timestep that's newer than a val/test timestep.
- Normalization stats are fit on **train only**.
- We **clip** standardized features to `[-8, 8]`. Without the clip, the
  rainfall column has values up to ~90 sigma (because most hours are 0
  mm but downpours are a few mm), and that destabilizes the GRU. Eight
  sigma is wide enough to keep real outliers "large".
- Wind direction is encoded as `(sin(deg), cos(deg))` so that 359 and 1
  are close, not opposite. Same trick for hour-of-day, day-of-week,
  and month-of-year.
- We train with **smooth-L1 loss in standardized space** and report
  metrics in original ug/m^3 after de-standardizing.
- **Spike recall** = fraction of test hours with `y >= 75 ug/m^3` where
  the model also predicted `>= 75 ug/m^3`. 75 is the WHO / Chinese GB
  "unhealthy" threshold.
